Cellular gateways software versions MG 26.2.2 changelog
Executive summary
This is the first GA release for the MG26.2 release family.
This release carries forward UI capabilities for configuring and managing cellular features, such as geolocation, band masking and more.
It also carries forward 464XLAT support to provide IPv4 connectivity over IPv6-only cellular networks.
It also delivers improvements in cellular connectivity, recovery, and Dashboard status reporting.
Bug fixes - general fixes
Resolved an issue that could prolong a downstream MX WAN outage after cellular session renegotiation on an MG in IP passthrough mode because the MX retained an unusable DHCP address. (MG-6768)
Fixed an issue where the Local Status Page reloads frequently on cellular state changes during debugging. (MG-7242)
Bug fixes - limited platform fixes
Fixed an issue on MG51/51E devices that could briefly display “No signal detected” for 4G in Dashboard while cellular connectivity remained stable. (MG-6922)
Legacy products notice
When configured for this version, MG21(E) devices will run MG 4.1.3.
