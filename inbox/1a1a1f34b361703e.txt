Executive summary MX 26.1.7.2 adds an option for Cisco Meraki Support to block client DNS over TCP traffic on affected MX networks. The control is disabled by default and leaves UDP DNS handling unchanged. Important notice When Cisco Meraki Support enables this control, client DNS over TCP traffic is blocked even when Umbrella DNS filtering is disabled. DNS lookups that require TCP may fail. What's new Added an option for Cisco Meraki Support to block client DNS over TCP traffic on affected MX networks. Known issues Networks configured with legacy IPv4 manual inbound firewall rules but no NAT Exceptions may have those rules hidden after upgrading to MX 26.1.3 or later. Before upgrading or making further configuration changes, enable NAT Exceptions, select Override NAT per VLAN, and keep NAT enabled for all VLANs to preserve the existing NAT configuration and inbound firewall rules. (MX-49643) On MX 26.1 appliances, Auto VPN tunnels may fail to establish over WAN 3 when it is the only active uplink and a peer is running firmware earlier than MX 26.1. (MX-50123) When IPsec VPN over multiple WAN uplinks is enabled, IKEv1 Client VPN connections may fail if upstream NAT changes the client's IKE source port from UDP 500. (MX-51712)
